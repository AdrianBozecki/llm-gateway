Quiz me on milestone **$ARGUMENTS** (if empty: the current milestone) (check questions are in the milestone
table in CLAUDE.md).

Ask the milestone's check questions **one at a time**, then 1–2 follow-ups about how *my*
code handles it (read the code first so the follow-ups are specific). Wait for my answer
before the next question. Don't give hints unless I ask.

After each answer: say what was right, what was missing or wrong, and where in my code or
the docs I can confirm it. At the end, list the topics I should revisit before moving on.
